# ระบบประกาศผลการเรียน + หลังบ้าน ปพ.5 / ปพ.6 (Google Apps Script)

## ระบบนี้ทำอะไรได้

**หน้าแรก (สำหรับผู้ปกครอง)** — เปิดลิงก์เว็บแอป
- กรอกเลขประจำตัวนักเรียน (และเลขบัตรประชาชน 4 ตัวท้าย ถ้าเปิดใช้) เพื่อดูผลการเรียน
- **ผลกลางปี** = คะแนนเก็บ/คะแนนสอบภาคเรียนที่ 1 (ไม่มีเกรด)
- **ผลปลายปี** = คะแนนรวมทั้งปี เกรด เกรดเฉลี่ย เวลาเรียน ผลการเลื่อนชั้น
- ถึงครูจะกรอกคะแนนยังไม่ครบทุกวิชา ก็แสดงคะแนนเก็บ/คะแนนสอบเท่าที่มี (วิชาที่ยังไม่มีแสดงเป็น –) และนักเรียนที่มีชื่อในทะเบียนแต่ยังไม่มีคะแนน จะขึ้นว่า "รอครูบันทึกคะแนน" แทน "ไม่พบข้อมูล"
- ผิดเกิน 8 ครั้ง ระบบล็อกการค้นหาเลขนั้น 10 นาที

**เข้าสู่ระบบ** — ปุ่ม **🔒 สำหรับครู** มุมขวาบนของหน้าแรก กดรหัสบนแป้นตัวเลข แล้วกด "ตกลง"
- รหัสครู `72030101` → ใช้งานหลังบ้านตามที่ผู้ดูแลเปิดไว้
- รหัสผู้ดูแลระบบหลัก `555666` → ใช้ได้ทุกอย่าง และมีปุ่ม **⚙ เปิด-ปิดระบบ** (หน้าประกาศผล, ผลกลางปี, ผลปลายปี, อัปโหลดไฟล์, กรอกคะแนน, ลบไฟล์, อัปโหลดรายชื่อ, เผยแพร่, สร้าง PDF) มีผลทันทีและตรวจที่เซิร์ฟเวอร์ด้วย
- เปลี่ยนรหัสได้ที่ `TEACHER_PIN` / `ADMIN_PIN` บนสุดของ `Code.gs` · ใส่รหัสผิดเกิน 20 ครั้งใน 10 นาที ระบบพักการเข้าสู่ระบบชั่วคราว

**หลังบ้าน (สำหรับครู)** — ลิงก์เว็บแอปต่อท้ายด้วย `?page=admin`
1. **อัปโหลดไฟล์ ปพ.5 / ปพ.6 (Excel)** ระบบคำนวณผลแล้วส่งขึ้นหน้าประกาศผลอัตโนมัติ
2. **กรอก ปพ.5 / ปพ.6 ในระบบ** ได้เลย (วางข้อมูลจาก Excel ได้)
3. **สร้างไฟล์ Excel ปพ.5 / ปพ.6 ในรูปแบบต้นฉบับ** (โปรแกรม ปพ.5 ครูหนุ่ม / ปพ.6 ของโรงเรียน) ไปกรอกในคอม แล้วอัปโหลดกลับมาให้ระบบวิเคราะห์
   - **บังคับใช้รูปแบบต้นฉบับเสมอ**: ระบบหยิบไฟล์ต้นฉบับของชั้น/วิชานั้นจากโฟลเดอร์ต้นฉบับของโรงเรียน (`SOURCE_FOLDER_ID` — อ่านอย่างเดียว ไม่แก้ไขไฟล์ในนั้น) มาล้างข้อมูลนักเรียนออก แล้วเก็บเป็นแม่แบบในโฟลเดอร์ `_แม่แบบ (ห้ามลบ)` ให้เอง ไฟล์ ปพ. ที่อัปโหลดเข้ามาก็ถูกใช้เป็นแม่แบบของวิชานั้นด้วย
   - ไฟล์ที่ดาวน์โหลดมีชีต **สารบัญ** เป็นหน้าแรก กดชื่อชีตเพื่อไปยังชีตนั้นได้ทันที
   - ตัวชี้วัด มาตรฐานรายวิชา รหัสวิชา ชั่วโมง คะแนนเต็ม เติมให้อัตโนมัติจากไฟล์ต้นฉบับปีที่แล้ว (แก้ไขได้) ชื่อโรงเรียน = วัดทุ่งแฝก ครูผู้สอนตามตารางสอนภาคเรียนที่ 1/2569 (เลือก/พิมพ์ชื่ออื่นได้)
   - ไฟล์ที่สร้างคงสูตร มาโคร การจัดหน้าพิมพ์ ปก และรูปแบบเดิมทั้งหมด ใส่ข้อมูลวิชา รายชื่อ ตัวชี้วัด คะแนนให้ เปิดใน Excel แล้วสูตรคำนวณใหม่เอง
   - ลายเซ็นครูประจำชั้นในแม่แบบ ปพ.6 ถูกเอาออก (เพราะเป็นของครูเฉพาะคน) โลโก้และลายเซ็นผู้บริหารยังอยู่
4. **ทะเบียนรายชื่อนักเรียน (ไฟล์ Word)**: อัปโหลดไฟล์ "รายชื่อนักเรียน ปี 25xx" (.docx) แถบด้านบนจะแสดง "อัปเดตรายชื่อตามข้อมูลวันที่ ..." พร้อมปุ่มดาวน์โหลดไฟล์ และอัปโหลดฉบับใหม่ได้ทุกเมื่อ
   - ใช้เป็นรายชื่อเริ่มต้นเมื่อกรอก/สร้าง ปพ.5 ปพ.6 ใหม่ และใช้เลขบัตร 4 ตัวท้ายยืนยันตัวตนผู้ปกครอง
   - ปุ่ม "ดูรายชื่อ" บนแถบรายชื่อ ดูรายชื่อทุกห้อง และเทียบกับไฟล์ ปพ. ในระบบ (ใครยังไม่มีในไฟล์ / ใครย้ายออก)
   - ไฟล์ทุกฉบับเก็บไว้ในโฟลเดอร์ `รายชื่อนักเรียน` (ฉบับเก่าไม่ถูกลบ ใช้ฉบับล่าสุด)
5. สร้างใบรายงาน ปพ.6 เป็น PDF (รวม / แยกรายคน, A4 / ครึ่ง A4)
6. แท็บ **ประกาศผล**: ตั้งชื่อหน้าเว็บ ข้อความประกาศ เปิด/ปิดผลกลางปี-ปลายปีของแต่ละปี และวิธีค้นหา

ไฟล์และโฟลเดอร์ทั้งหมดถูกสร้าง **ภายในโฟลเดอร์ Google Drive ที่กำหนดใน `ROOT_FOLDER_ID` เท่านั้น**

## วิธีติดตั้ง (ทำบนคอมพิวเตอร์ ครั้งเดียว)

1. เปิด https://script.google.com → **โปรเจ็กต์ใหม่** → ตั้งชื่อ เช่น `ประกาศผลการเรียน`
2. วางเนื้อหา `Code.gs` ทับของเดิม (ตั้งค่าบนสุดไว้ให้แล้ว):
   - `TEACHER_PIN = '72030101'` รหัสครู · `ADMIN_PIN = '555666'` รหัสผู้ดูแลระบบหลัก
   - `ROOT_FOLDER_ID` โฟลเดอร์ที่ระบบสร้างไฟล์ทั้งหมด · `SOURCE_FOLDER_ID` โฟลเดอร์ไฟล์ต้นฉบับ ปพ.5/ปพ.6 (อ่านอย่างเดียว)
3. สร้างไฟล์ HTML ทีละไฟล์จนครบตามตาราง: กด **+** → **HTML** → พิมพ์ชื่อ (ไม่ต้องมี .html, ตัวพิมพ์ใหญ่-เล็กต้องตรง) → วางเนื้อหา
4. กด **บันทึก**
5. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์
   (ถ้าขึ้น "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง** → **ไปที่...** → **อนุญาต**)
6. **การทำให้ใช้งานได้** → **การทำให้ใช้งานได้รายการใหม่** → เฟือง → **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ผู้ปกครองเปิดได้โดยไม่ต้องล็อกอิน Google)
   - กด **ทำให้ใช้งานได้** แล้วคัดลอก URL (ลงท้าย `/exec`)
7. เปิด URL แล้วกด **🔒 สำหรับครู** มุมขวาบน กดรหัส แล้วเริ่มใช้งาน
8. ส่ง URL (ไม่มี `?page=admin`) ให้ผู้ปกครอง

> บัญชีที่ติดตั้งสคริปต์ต้องมีสิทธิ์ **แก้ไข** โฟลเดอร์ใน `ROOT_FOLDER_ID` และสิทธิ์ **ดู** โฟลเดอร์ใน `SOURCE_FOLDER_ID`

## เรื่องความปลอดภัยของข้อมูลนักเรียน

- ค่าเริ่มต้นค้นหาด้วย **เลขประจำตัวนักเรียนอย่างเดียว** ตามที่ขอ แต่เลขประจำตัวมักเรียงกัน ใครก็ลองพิมพ์เลขแล้วเห็นผลของเด็กคนอื่นได้
- แนะนำให้เปลี่ยนเป็น **เลขประจำตัว + เลขบัตรประชาชน 4 ตัวท้าย** ในแท็บ "ประกาศผล"
  (เลข 4 ตัวท้ายดึงจากชีตรายชื่อใน ปพ.5 หรือกรอกในแท็บ "นักเรียน" ของการกรอกในระบบ — ระบบเก็บแค่ 4 ตัวท้าย)
- หน้าประกาศผลส่งข้อมูลกลับมาเฉพาะของนักเรียนคนที่ค้นหาเท่านั้น

## เมื่อมีโค้ดรุ่นใหม่

วางไฟล์ที่เปลี่ยนทับ (ชื่อตรงกัน) → บันทึก → **การทำให้ใช้งานได้** → **จัดการการทำให้ใช้งานได้** → ดินสอ → เวอร์ชัน **ใหม่** → **ทำให้ใช้งานได้** (URL เดิมใช้ได้ต่อ)

## ข้อมูลเก็บที่ไหน (ภายในโฟลเดอร์หลัก)

```
โฟลเดอร์หลัก (ROOT_FOLDER_ID)/
├── ปีการศึกษา 2568/ป.4-2/        ← ไฟล์ ปพ.5 / ปพ.6 (เปลี่ยนชื่อให้แล้ว)
├── รายชื่อนักเรียน/              ← ไฟล์ Word รายชื่อนักเรียนทุกฉบับที่อัปโหลด
├── PDF ใบรายงาน/                ← สำเนา PDF ที่สร้าง
├── _แม่แบบ (ห้ามลบ)/             ← แม่แบบ ปพ.5 / ปพ.6 รูปแบบต้นฉบับ (ไม่มีข้อมูลนักเรียน)
├── _ข้อมูลระบบ (ห้ามลบ)/         ← ข้อมูลที่ระบบถอดแล้ว
└── _ประกาศผล (ห้ามลบ)/           ← ข้อมูลที่ผู้ปกครองค้นหาได้
```

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| "เปิดโฟลเดอร์หลักใน Google Drive ไม่ได้" | บัญชีที่ติดตั้งไม่มีสิทธิ์แก้ไขโฟลเดอร์ หรือ `ROOT_FOLDER_ID` ผิด |
| ไม่พบไฟล์ HTML ชื่อ ... | ชื่อไฟล์ใน Apps Script ไม่ตรงตาราง (เช่น `css` แทน `Css`) |
| ผู้ปกครองค้นไม่เจอ | นักเรียนต้องมีเลขประจำตัวในไฟล์ / ตรวจว่าเปิดผลของปีนั้นในแท็บ "ประกาศผล" / ถ้าใช้ 4 ตัวท้าย ต้องมีเลขบัตรในข้อมูล |
| ขึ้นว่า "ยังไม่พบไฟล์ต้นฉบับ" | ตรวจว่าบัญชีที่ติดตั้งเปิดโฟลเดอร์ `SOURCE_FOLDER_ID` ได้ หรืออัปโหลดไฟล์ ปพ.5 / ปพ.6 ต้นฉบับ 1 ไฟล์ |
| ปุ่มอัปโหลด/กรอกคะแนนหายไป | ผู้ดูแลระบบหลักปิดระบบนั้นไว้ (เข้าด้วยรหัส 555666 → ⚙ เปิด-ปิดระบบ) |
| "แม่แบบรองรับนักเรียนได้สูงสุด ..." | แม่แบบ ปพ.5 รับได้ 40 คน, ปพ.6 รับได้ 36 คน (ตามไฟล์ต้นฉบับ) |
| ผลปลายปีไม่ขึ้น | ต้องมีคะแนนครบทั้ง 2 ภาค (ปพ.6) หรือมีเกรดครบทุกวิชา (ปพ.5) |
| "ยังโหลดตัวอ่านไฟล์ Excel ไม่สำเร็จ" | ตรวจอินเทอร์เน็ต แล้วรีเฟรช (ระบบโหลดเครื่องมือจาก cdnjs.cloudflare.com) |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้องทำ "เวอร์ชันใหม่" ตามหัวข้อด้านบน |
