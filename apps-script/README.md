# ระบบประกาศผลการเรียน + หลังบ้าน ปพ.5 / ปพ.6 (Google Apps Script)

## ระบบนี้ทำอะไรได้

**หน้าแรก (สำหรับผู้ปกครอง)** — เปิดลิงก์เว็บแอป
- กรอกเลขประจำตัวนักเรียน (และเลขบัตรประชาชน 4 ตัวท้าย ถ้าเปิดใช้) เพื่อดูผลการเรียน
- **ผลกลางปี** = คะแนนเก็บ/คะแนนสอบภาคเรียนที่ 1 (ไม่มีเกรด)
- **ผลปลายปี** = คะแนนรวมทั้งปี เกรด เกรดเฉลี่ย เวลาเรียน ผลการเลื่อนชั้น
- ผิดเกิน 8 ครั้ง ระบบล็อกการค้นหาเลขนั้น 10 นาที

**หลังบ้าน (สำหรับครู)** — ลิงก์เว็บแอปต่อท้ายด้วย `?page=admin` (มีลิงก์ "สำหรับครู" ท้ายหน้าแรก)
1. **อัปโหลดไฟล์ ปพ.5 / ปพ.6 (Excel)** ระบบคำนวณผลแล้วส่งขึ้นหน้าประกาศผลอัตโนมัติ
2. **กรอก ปพ.5 / ปพ.6 ในระบบ** ได้เลย (วางข้อมูลจาก Excel ได้)
3. **สร้างไฟล์ Excel ปพ.5 / ปพ.6** ไปกรอกในคอม แล้วอัปโหลดกลับมาให้ระบบวิเคราะห์
4. สร้างใบรายงาน ปพ.6 เป็น PDF (รวม / แยกรายคน, A4 / ครึ่ง A4)
5. แท็บ **ประกาศผล**: ตั้งชื่อหน้าเว็บ ข้อความประกาศ เปิด/ปิดผลกลางปี-ปลายปีของแต่ละปี และวิธีค้นหา

ไฟล์และโฟลเดอร์ทั้งหมดถูกสร้าง **ภายในโฟลเดอร์ Google Drive ที่กำหนดใน `ROOT_FOLDER_ID` เท่านั้น**

## วิธีติดตั้ง (ทำบนคอมพิวเตอร์ ครั้งเดียว)

1. เปิด https://script.google.com → **โปรเจ็กต์ใหม่** → ตั้งชื่อ เช่น `ประกาศผลการเรียน`
2. วางเนื้อหา `Code.gs` ทับของเดิม แล้วแก้ 2 บรรทัดบนสุด:
   - `var ACCESS_PIN = '';` → ใส่รหัสผ่านหลังบ้าน เช่น `'2568'`
   - `var ROOT_FOLDER_ID = '...';` → ตั้งไว้เป็นโฟลเดอร์ของคุณแล้ว (เปลี่ยนได้ถ้าต้องการใช้โฟลเดอร์อื่น)
3. สร้างไฟล์ HTML ทีละไฟล์จนครบตามตาราง: กด **+** → **HTML** → พิมพ์ชื่อ (ไม่ต้องมี .html, ตัวพิมพ์ใหญ่-เล็กต้องตรง) → วางเนื้อหา
4. กด **บันทึก**
5. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์
   (ถ้าขึ้น "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง** → **ไปที่...** → **อนุญาต**)
6. **การทำให้ใช้งานได้** → **การทำให้ใช้งานได้รายการใหม่** → เฟือง → **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ผู้ปกครองเปิดได้โดยไม่ต้องล็อกอิน Google)
   - กด **ทำให้ใช้งานได้** แล้วคัดลอก URL (ลงท้าย `/exec`)
7. เปิด URL + `?page=admin` เพื่อเข้าหลังบ้าน ใส่รหัสผ่าน แล้วเริ่มใช้งาน
8. ส่ง URL (ไม่มี `?page=admin`) ให้ผู้ปกครอง

> บัญชีที่ติดตั้งสคริปต์ต้องมีสิทธิ์ **แก้ไข** โฟลเดอร์ใน `ROOT_FOLDER_ID`

## เรื่องความปลอดภัยของข้อมูลนักเรียน

- ค่าเริ่มต้นค้นหาด้วย **เลขประจำตัวนักเรียนอย่างเดียว** ตามที่ขอ แต่เลขประจำตัวมักเรียงกัน ใครก็ลองพิมพ์เลขแล้วเห็นผลของเด็กคนอื่นได้
- แนะนำให้เปลี่ยนเป็น **เลขประจำตัว + เลขบัตรประชาชน 4 ตัวท้าย** ในแท็บ "ประกาศผล"
  (เลข 4 ตัวท้ายดึงจากชีตรายชื่อใน ปพ.5 หรือกรอกในแท็บ "นักเรียน" ของการกรอกในระบบ — ระบบเก็บแค่ 4 ตัวท้าย)
- หน้าประกาศผลส่งข้อมูลกลับมาเฉพาะของนักเรียนคนที่ค้นหาเท่านั้น

## เมื่อมีโค้ดรุ่นใหม่

วางไฟล์ที่เปลี่ยนทับ (ชื่อตรงกัน) → บันทึก → **การทำให้ใช้งานได้** → **จัดการการทำให้ใช้งานได้** → ดินสอ → เวอร์ชัน **ใหม่** → **ทำให้ใช้งานได้** (URL เดิมใช้ได้ต่อ)

## ข้อมูลเก็บที่ไหน (ภายในโฟลเดอร์หลัก)

```
โฟลเดอร์หลัก (ROOT_FOLDER_ID)/
├── ปีการศึกษา 2568/ป.4-2/        ← ไฟล์ ปพ.5 / ปพ.6 (เปลี่ยนชื่อให้แล้ว)
├── PDF ใบรายงาน/                ← สำเนา PDF ที่สร้าง
├── _ข้อมูลระบบ (ห้ามลบ)/         ← ข้อมูลที่ระบบถอดแล้ว
└── _ประกาศผล (ห้ามลบ)/           ← ข้อมูลที่ผู้ปกครองค้นหาได้
```

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| "เปิดโฟลเดอร์หลักใน Google Drive ไม่ได้" | บัญชีที่ติดตั้งไม่มีสิทธิ์แก้ไขโฟลเดอร์ หรือ `ROOT_FOLDER_ID` ผิด |
| ไม่พบไฟล์ HTML ชื่อ ... | ชื่อไฟล์ใน Apps Script ไม่ตรงตาราง (เช่น `css` แทน `Css`) |
| ผู้ปกครองค้นไม่เจอ | นักเรียนต้องมีเลขประจำตัวในไฟล์ / ตรวจว่าเปิดผลของปีนั้นในแท็บ "ประกาศผล" / ถ้าใช้ 4 ตัวท้าย ต้องมีเลขบัตรในข้อมูล |
| ผลปลายปีไม่ขึ้น | ต้องมีคะแนนครบทั้ง 2 ภาค (ปพ.6) หรือมีเกรดครบทุกวิชา (ปพ.5) |
| "ยังโหลดตัวอ่านไฟล์ Excel ไม่สำเร็จ" | ตรวจอินเทอร์เน็ต แล้วรีเฟรช (ระบบโหลดเครื่องมือจาก cdnjs.cloudflare.com) |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้องทำ "เวอร์ชันใหม่" ตามหัวข้อด้านบน |
