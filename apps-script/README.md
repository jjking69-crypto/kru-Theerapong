# ระบบวิเคราะห์ผลการเรียน ปพ.5 / ปพ.6 — รุ่น Google Apps Script

ระบบเว็บสำหรับครู: อัปโหลดไฟล์ ปพ.5 (รายวิชา) และ ปพ.6 (ใบรายงานทั้งห้อง) แล้ว

- ถอดคะแนนตามตัวชี้วัด เกรด เวลาเรียน คุณลักษณะ อ่านคิดเขียน กิจกรรม
- ดูผลรายวิชา สรุปทั้งห้อง และรายบุคคล
- สร้างใบรายงาน ปพ.6 เป็น PDF รวมทุกคน หรือแยกรายคน ขนาดเต็ม A4 หรือครึ่ง A4
- **ไฟล์ทั้งหมดเก็บใน Google Drive ของผู้ติดตั้ง** ครูทุกคนและทุกเครื่องเห็นข้อมูลชุดเดียวกัน

## ไฟล์ที่ต้องใช้ (อยู่ในโฟลเดอร์นี้)

| ไฟล์ | วางที่ไหนใน Apps Script |
|---|---|
| `Code.gs` | ไฟล์ `Code.gs` (แทนที่ของเดิมทั้งหมด) |
| `Index.html` | ไฟล์ HTML ใหม่ชื่อ `Index` |
| `appsscript.json` | ไม่ต้องใช้ ถ้าติดตั้งแบบคัดลอกวาง (สำหรับผู้ใช้ clasp เท่านั้น) |

## วิธีติดตั้ง (ประมาณ 10 นาที ทำบนคอมพิวเตอร์)

1. เปิด https://script.google.com แล้วกด **โปรเจ็กต์ใหม่**
2. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เช่น `ระบบ ปพ.5-ปพ.6`
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs`
4. **ตั้งรหัสผ่าน:** ในบรรทัด `var ACCESS_PIN = '';` ใส่รหัสระหว่างเครื่องหมาย `'` เช่น `var ACCESS_PIN = '2568';`
   (แนะนำให้ตั้ง เพราะมีคะแนนและข้อมูลนักเรียน)
5. กดเครื่องหมาย **+** ข้าง "ไฟล์" → **HTML** → ตั้งชื่อ `Index` (ตัว I ใหญ่ ไม่ต้องพิมพ์ .html)
   ลบโค้ดเดิมในไฟล์นั้น แล้ววางเนื้อหาทั้งหมดจากไฟล์ `Index.html`
6. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)
7. **อนุญาตสิทธิ์ครั้งแรก:** เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **เรียกใช้**
   - Google จะถามสิทธิ์เข้าถึง Drive → เลือกบัญชีของคุณ
   - ถ้าขึ้น "Google ไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง** → **ไปที่ ระบบ ปพ.5-ปพ.6 (ไม่ปลอดภัย)** → **อนุญาต**
     (เป็นสคริปต์ของคุณเอง จึงปลอดภัย)
   - ระบบจะสร้างโฟลเดอร์ `ระบบวิเคราะห์ผล ปพ.5-ปพ.6` ใน Drive ของคุณ
8. **เผยแพร่เป็นเว็บ:** กด **การทำให้ใช้งานได้** → **การทำให้ใช้งานได้รายการใหม่**
   - กดไอคอนเฟือง → เลือก **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ครูเปิดได้โดยไม่ต้องล็อกอิน แต่ต้องใส่รหัสผ่าน) หรือ **ทุกคนที่มีบัญชี Google**
   - กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
9. เปิด URL นั้น ใส่รหัสผ่าน แล้วเริ่มอัปโหลดไฟล์ได้เลย

> ส่ง URL ให้ครูคนอื่นได้เลย ทุกคนจะเห็นข้อมูลชุดเดียวกัน ระบบจำรหัสผ่านไว้ในเครื่องที่เคยใส่แล้ว

## เมื่ออัปเดตโค้ดรุ่นใหม่

วางโค้ดใหม่ทับใน `Code.gs` และ `Index` → บันทึก → **การทำให้ใช้งานได้** → **จัดการการทำให้ใช้งานได้**
→ กดไอคอนดินสอ → เวอร์ชัน: **เวอร์ชันใหม่** → **ทำให้ใช้งานได้** (URL เดิมยังใช้ได้)

## ข้อมูลเก็บที่ไหน

ใน Google Drive ของผู้ติดตั้ง โฟลเดอร์ `ระบบวิเคราะห์ผล ปพ.5-ปพ.6`:

```
ระบบวิเคราะห์ผล ปพ.5-ปพ.6/
├── ปีการศึกษา 2568/
│   └── ป.4-2/
│       ├── ป.4-2_ส14101_สังคมศึกษา ศาสนา และวัฒนธรรม_ปี2568.xlsm   ← ไฟล์ที่อัปโหลด (เปลี่ยนชื่อให้แล้ว)
│       └── ป.4-2_ปพ6_รายงานผลรายบุคคล_ปี2568.xlsx
├── PDF ใบรายงาน/          ← สำเนา PDF ที่สร้างจากระบบ
└── _ข้อมูลระบบ (ห้ามลบ)/   ← ข้อมูลที่ระบบถอดแล้ว
```

- อัปโหลดไฟล์วิชาเดิมซ้ำ = แทนที่ไฟล์เก่า (ไฟล์เก่าย้ายไปถังขยะ กู้คืนได้ 30 วัน)
- แตะไอคอน 📁 มุมซ้ายบนของหน้าเว็บเพื่อเปิดโฟลเดอร์ใน Drive
- ระบบไม่อ่านเลขประจำตัวประชาชนของนักเรียน

## ใส่ในแอปห้องเรียนเดิม

ถ้าต้องการเปิดจากแอปห้องเรียนครูธีรพงศ์ ให้ใช้ลิงก์ URL ของเว็บแอป (`.../exec`) ทำเป็นปุ่มหรือลิงก์ได้เลย
ระบบตั้งค่าให้แสดงใน iframe ได้แล้ว

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น "ยังโหลดตัวอ่านไฟล์ Excel ไม่สำเร็จ" | ตรวจอินเทอร์เน็ต แล้วรีเฟรชหน้า (ระบบโหลดตัวอ่าน Excel และตัวสร้าง PDF จาก cdnjs.cloudflare.com) |
| ใส่รหัสผ่านแล้วถามซ้ำ | รหัสไม่ตรงกับ `ACCESS_PIN` ใน Code.gs |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้องทำ "เวอร์ชันใหม่" ตามหัวข้อ "เมื่ออัปเดตโค้ดรุ่นใหม่" |
| ดาวน์โหลด PDF ไม่ได้บนบางเครื่อง | ระบบเก็บสำเนาไว้ในโฟลเดอร์ `PDF ใบรายงาน` ใน Drive ให้อัตโนมัติ เปิดจากตรงนั้นได้ |
| ไฟล์ใหญ่เกิน 40 MB | Apps Script รับไฟล์ขนาดนั้นไม่ได้ ใช้ PDF แยกรายคน (ZIP) หรือพิมพ์ผ่านปุ่ม "พิมพ์" แทน |

## สำหรับผู้พัฒนา

โค้ดหน้าเว็บหลักอยู่ที่ `pp5/` (ใช้ได้ทั้งแบบเว็บธรรมดาที่เก็บข้อมูลในเครื่อง และแบบ Apps Script)
ไฟล์ในโฟลเดอร์นี้สร้างอัตโนมัติด้วยคำสั่ง:

```
python3 apps-script/build.py
```

แก้ไขที่ `pp5/*.js`, `apps-script/src/Code.gs` หรือ `apps-script/src/store.js` แล้วรันคำสั่งด้านบนใหม่ อย่าแก้ `Index.html` โดยตรง
